# ¿Qué es Tuspot?

Tuspot es una plataforma tecnológica mexicana para descubrir, comparar y reservar lugares para eventos.

Nuestra misión es convertirnos en la plataforma líder en México y Latinoamérica para la renta de espacios destinados a eventos sociales, empresariales y recreativos.

Tuspot busca ofrecer una experiencia tan sencilla y confiable como Airbnb, pero especializada en lugares para eventos.

---

# Visión

Ser la plataforma número uno en Latinoamérica para reservar espacios para eventos.

Cuando una persona piense:

"Necesito un lugar para mi evento"

la primera opción que venga a su mente debe ser Tuspot.

---

# Misión

Conectar anfitriones que tienen espacios disponibles con personas que necesitan organizar un evento de forma rápida, segura y sencilla.

---

# Objetivos del proyecto

Construir una plataforma moderna que permita:

- Buscar lugares.
- Filtrar resultados.
- Ver fotografías.
- Consultar disponibilidad.
- Reservar fechas.
- Contactar anfitriones.
- Publicar nuevos lugares.
- Administrar reservas.
- Gestionar pagos.

---

# Público objetivo

Tuspot está dirigido a:

- Familias
- Organizadores de eventos
- Empresas
- Escuelas
- Universidades
- Personas que buscan celebrar cumpleaños, bodas, reuniones o eventos privados.

---

# Filosofía

Cada decisión de desarrollo debe acercar a Tuspot a convertirse en el Airbnb de los lugares para eventos.

No desarrollar funciones innecesarias.

Priorizar siempre:

- Simplicidad.
- Rapidez.
- Diseño limpio.
- Facilidad de uso.
- Escalabilidad.
