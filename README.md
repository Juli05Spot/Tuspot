# 🏡 Tuspot

> **La plataforma para descubrir y reservar lugares para eventos en México.**

Tuspot es una plataforma tecnológica diseñada para conectar personas que buscan un lugar para realizar un evento con propietarios que desean rentar sus espacios.

Nuestro objetivo es convertirnos en la plataforma líder en México y Latinoamérica para la renta de espacios para eventos, ofreciendo una experiencia moderna, rápida y confiable.

---

# 🌟 Visión

Convertirnos en la plataforma de referencia para la reserva de espacios para eventos en Latinoamérica.

Cuando alguien piense:

> "Necesito un lugar para mi evento"

Queremos que piense inmediatamente en **Tuspot**.

---

# 🎯 Misión

Facilitar la búsqueda y reserva de espacios para eventos mediante una plataforma intuitiva, segura y accesible para clientes y anfitriones.

---

# ✨ Funcionalidades actuales
